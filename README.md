# The Valley

A medieval village simulation game built with vanilla JS + Vite.

## Dev

```bash
npm install
npm run dev
```

## Deploy

Connected to Vercel — every push to `main` triggers a deploy.

## Architecture

- `index.html` — entry shell
- `src/style.css` — all styles
- `src/main.js` — full game logic (canvas render, simulation, UI, economy, influence chain)
